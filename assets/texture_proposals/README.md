黒柴の原本は、PetsのGrant（pet_6ac2d603d01c8191ba9c203d3cdcbcae）に対応する実画像です。茶・白の5点は座った姿の単独プレビューで、完成したアニメーションアトラスではありません。ゲーム用の本番素材として使える状態ではなく、色味・見た目の承認待ちです。初版を保持し、改訂版を追加しています。

親スレッドで試作した茶・白の全アトラスには輪郭のハロー／ノイズがあり、採用されていません。このフォルダにはその全アトラスを含めていません。プレビューの輪郭品質も本番採用前の確認対象です。

今回は素材の保存のみです。ゲームのHTML・編集用ソース・公開用ZIP・Cloudflare公開版を変更していません。現在のゲーム内の柴犬は従来の暫定Canvas絵柄のままです。見た目の承認を受けてから、アニメーション素材の制作と組み込みを次の工程で進めます。

metadata.json に各Library ID、ファイルID、バージョン、寸法、SHA-256を記録しています。公式Library転送ヘルパーを使用し、Windowsでは拡張属性をNTFS代替データストリームに保存して、原子配置後に読み戻して検証しました。ZIPや別ファイルシステムへ移すと代替データストリームが失われる場合があるため、識別情報はmetadata.jsonにも残しています。期限付きダウンロードURLや認証情報は含めていません。

最新版の色味確認用プレビューは、茶が grant-brown-preview-v3.png、白が grant-white-preview-v2.png です。茶の第3版は、初版の赤茶と第2版の焦げ茶の中間にあたる栗色です。過去版はそのまま保持しています。

承認された元黒柴、茶v3、白v2をゲームへ元PNGのまま埋め込みました。茶柴/白柴は１枚絵の移動・反転で、全フレームアトラスへの変換は行っていません。取得時の履歴はmetadata.jsonに保持し、今回の用途はintegration.jsonに分けて記録しています。
