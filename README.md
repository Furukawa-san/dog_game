# しば日和 3D — 小さな家族と、毎日。

iPadのタッチ操作を想定した柴犬育成ゲームです。版: `2026-10-24-3d-v7.3`。
おうち・散歩道・遊び場を **WebGLの3D空間** にし、柴犬は **承認済みのGrant画像をそのまま** 3D空間の中で動かしています（画素の変更なし）。ミニゲームは3種から **10種＋おさんぽ5コース** に増えました。外部ライブラリ・CDN・広告・課金・解析・外部通信はありません。

- 自己完結版: `index.html`（Grant画像を埋め込み済み、約6.7MB）
- PWA配信用: `pwa/` の7ファイル、まとめたZIPは `cloudflare-upload-3d-v4.zip`
- 更新前の版: `backups/pre-3d-v4-20261022.zip`（旧ソース・旧説明書・旧テスト・証跡を保全）

## 遊び方

### おうち（3D）
- 床をタッチ: 柴犬がそこへ歩きます（遠いと走ります）。
- 柴犬をタッチ: 機嫌に合わせて喜ぶ・しょんぼり・ぷんぷんの反応。指でなで続けるとハートが出ます。
- ボールをタッチ: 転がったボールを柴犬が取ってきます。
- 横になぞる: 部屋の向きが少し変わります。2本指でつまむと拡大・縮小。
- 柴犬は放っておくと、歩き回る・においをかぐ・ボールで遊ぶ・おすわり・ベッドで寝るなど自由に過ごします。おなかがすくとお皿の前へ行き、頭の上に「してほしいこと」のアイコンが出ます。
- 窓の空と部屋の明るさは端末の時刻（あさ・ひる・ゆうがた・よる）で変わります。

## 茶柴・白柴について
黒柴はスプライトシートの全ポーズ（走り左右・おて・喜ぶ・しょんぼり・おふろ・ぷんぷん・食べる・16方向の顔向き）を使います。**茶柴・白柴は承認済みの1枚絵を、移動・左右反転・弾み・傾き・伸び縮み・回転で表現しています（全ポーズのアニメーションはありません）。** その範囲で、食べる（お皿へ前かがみ）・ふせ・おすわり・おて（足あと表示）・くるりん・ちんちん・ばーん（ころん）などの動作が分かるようにしています。
きせかえは、表示中の画像の不透明な部分から頭の位置と幅をその場で読み取り、頭・目・首に合わせて重ねます（走るときは進行方向側を頭として扱います）。

## 育成記録とバックアップ
- 保存は端末内（localStorage）です。新しい記録キーは `shiba-pocket-save-v3`、JSONは `schemaVersion: 3`。
- **旧版（v2）の記録は自動で引き継ぎます。** 旧キー `shiba-pocket-save-v2` は消さずに残します。旧版のJSONバックアップ（schemaVersion 2）も読み込めます（読み込み時にv3へ変換）。
- 設定→「記録を保存」で `shiba-record-v3.json` を保存。保存できない環境は「テキストで保存・読み込む」。読み込み前に確認が出ます。不正な形式・範囲外の値・未知のバージョンは拒否し、今の記録を保持します。
- キャッシュ・サイトデータの削除、端末やURLの変更、アプリ削除の前にJSONを保存してください。

写真は端末内で処理し、送信しません。写真は育成記録に含まれず、画面を閉じると失われます。

## iPadで使う
1. 公開URLはこの版に更新済みです（自分で配置し直す場合は `pwa/` の7ファイル、または `cloudflare-upload-3d-v4.zip` の中身を、HTTPSの同じ配信先へ配置）。Service Workerの版は `2026-10-24-3d-v7.3` に上げてあり、旧版から開くと「新しい版に更新」が出ます。更新前にJSONのバックアップを勧めます。
2. iPadのSafariで開き、共有→「ホーム画面に追加」。ホーム画面から開き直すと全画面で遊べます。
3. 初回の読み込み後はオフラインでも遊べます（オフライン準備の表示を確認してください）。

`index.html` 単体をPCのChrome/Edgeで開いて遊ぶこともできます（この場合PWAのオフライン機能は使いません）。WebGLが使えない環境では、その旨のお知らせを表示します（旧版の「軽量2D」モードはありません）。

## iPad向けの対応
- 全画面のタッチ操作（ピンチ・ダブルタップでページが拡大しない）、縦横どちらでも崩れない配置、セーフエリア（ノッチ・ホームバー）に対応。
- 音はiOSの決まりに合わせ、最初のタッチ（指を離したとき）で有効になります。消音スイッチがオンだと鳴らない場合があります。
- iPadOS 15.4より前のSafariにない機能（`<dialog>`、`Object.hasOwn`）は代わりの処理を入れています。WebGL 1 だけで動きます。
- 描画が重いときは解像度を自動で少し下げて、なめらかさを保ちます。
